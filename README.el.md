# Planoptis

[English](README.md) · **Ελληνικά** — [planoptis.com](https://www.planoptis.com)

Ένα planning format σε καθαρό κείμενο, για όσους θέλουν bullet journal χωρίς
εφαρμογή.

Ένα `.txt` αρχείο, indentation με tabs, ανοιγμένο σε editor που κάνει folding
βάσει indentation (Sublime Text, αλλά δουλεύει οποιοσδήποτε editor με folding).
Κάνε collapse έναν μήνα για να δεις τη χρονιά, expand μια μέρα για να δεις τη
δουλειά. Χωρίς βάση δεδομένων, χωρίς lock-in, grep-άρεται για πάντα,
συγχρονίζεται παντού, επιβιώνει από κάθε εφαρμογή που κάποτε θα κλείσει.

> **Το όνομα.** Το Planoptis είναι εμπνευσμένο από την ελληνική λέξη «πανόπτης» —
> αυτός που τα βλέπει όλα. Αντικατέστησε το «pan» με «plan» και προκύπτει ένα
> σύστημα σχεδιασμού χτισμένο γύρω από μία ιδέα: να έχεις όλο σου το πλάνο ορατό
> ανά πάσα στιγμή.

Δύο demo αρχεία δείχνουν όλο το σύστημα σε χρήση:

- [`planoptis-demo-el.txt`](planoptis-demo-el.txt)
- [`planoptis-demo-en.txt`](planoptis-demo-en.txt) — το format είναι ανεξάρτητο γλώσσας

## Ανατομία του αρχείου

Ένα plan έχει τρεις ενότητες πρώτου επιπέδου, η καθεμία με μια επικεφαλίδα-icon:

| Ενότητα | Επικεφαλίδα | Σκοπός |
|---|---|---|
| Projects | `💻 PROJECTS` | Τα σταθερά projects και ο σκοπός τους. Αλλάζει σπάνια. |
| Monthly plan | `🗒️ MONTHLY PLAN` | Ένα block ανά μήνα. Ο τρέχων μήνας σημειώνεται με `🟩`. |
| Daily log | `🗓️ SEPTEMBER` | Ένα block ανά μήνα, μετά ένα block ανά μέρα, μετά η δουλειά. |

Μέσα στο daily log, κάθε μέρα ομαδοποιείται ανά **θέμα / πελάτη**: μια γραμμή-label
ακολουθούμενη από γραμμή `-----`, και μετά τα tasks αυτού του θέματος.

```
🗓️ SEPTEMBER
=======================================================
=======================================================

	Tuesday 01-09-2026
	=============================================

		Website
		-----------------------------------------
		- ✅ Create repository
		- Responsive menu
		- Contact form
			| Validate before submit
```

## Indentation & folding

- **Indentation με tabs.** Ένα tab ανά επίπεδο. Η συνέπεια είναι αυτό που κάνει το
  folding και το highlighting να δουλεύουν.
- Fold/unfold από τα τριγωνάκια στο gutter του editor ή από τις εντολές code
  folding. Collapse για γρήγορη εποπτεία, expand για δουλειά.
- Κράτα σύντομες γραμμές. Οι μεγάλες γραμμές βγαίνουν εκτός οθόνης· βάλε τη
  λεπτομέρεια σε `|` notes στο επόμενο επίπεδο αντί για μία μακροσκελή πρόταση.

## Λεξιλόγιο γραμμών

### Δομή

| Γραμμή | Σημασία |
|---|---|
| `PLANOPTIS — …` | Πρώτη γραμμή, ο τίτλος του plan. |
| επικεφαλίδα `💻` / `🗒️` / `🗓️` | Μία από τις τρεις ενότητες πρώτου επιπέδου. |
| `SEPTEMBER` | Επικεφαλίδα μήνα. |
| `🟩 SEPTEMBER` | Ο **τρέχων μήνας** — το όνομά του χρωματίζεται διαφορετικά. |
| `Tuesday 01-09-2026` | Επικεφαλίδα ημέρας. Ημέρα + `DD-MM-YYYY`. |
| `Label` πάνω από γραμμή `-----` | Ομαδοποίηση θέματος / πελάτη μέσα στη μέρα. |
| `=====` , `-----` | Οπτικοί διαχωριστές. |

### Tasks

Κάθε task είναι μια γραμμή `-`. Ο marker είναι ένα emoji αμέσως **μετά την παύλα**:
`- <marker> κείμενο`. Χωρίς marker = απλό ανοιχτό task.

| Marker | Γραμμή | Σημαίνει | Χρώμα |
|---|---|---|---|
| _(κανένα)_ | `- Responsive menu` | Ανοιχτό task | default |
| `✅` | `- ✅ Create repository` | Ολοκληρώθηκε | πράσινο |
| `🆘` | `- 🆘 Renew server before expiration` | Επείγον / blocking | κόκκινο |
| `⚠️` | `- ⚠️ Check mobile layout` | Προσοχή / ρίσκο / θέλει έλεγχο | amber |
| `⏭️` | `- ⏭️ Prepare demo` | Αναβλήθηκε — επόμενο / μεταφέρθηκε | accent |
| `➡️` | `- ➡️ Send figures to Maria` | Ανατέθηκε / πέρασε σε άλλον | accent |

Το `⏩` γίνεται δεκτό ως alias του `⏭️`.

### Notes

| Γραμμή | Σημασία |
|---|---|
| `\| λεπτομέρεια` | Σημείωση ή υπο-λεπτομέρεια κάτω από το task από πάνω, ένα επίπεδο πιο μέσα. |

Χρησιμοποίησε `|` notes για υπο-βήματα, κριτήρια αποδοχής, αποφάσεις, και ό,τι
αλλιώς θα έκανε τη γραμμή του task υπερβολικά μεγάλη.

---

## Κανόνας θέσης του marker

Οι markers μπαίνουν πάντα **αμέσως μετά την `-`**, ένας ανά γραμμή:

```
- 🆘 Check available disk space      ✅ σωστό
🆘 - Check available disk space      ✗ παλιός τύπος (χρωματίζεται ακόμα, μη γράφεις καινούριους)
- Check available disk space 🆘      ✗ δεν αναγνωρίζεται
```

## Template νέας μέρας

Αντίγραψε αυτό το block για να ξεκινήσεις νέα μέρα στο daily log — επικεφαλίδα
μέρας σε ένα tab, labels θεμάτων σε δύο:

```
	Wednesday 03-09-2026
	=============================================

		Θέμα / Πελάτης
		-----------------------------------------
		- 
			| 
```

Μετονόμασε τη μέρα, βάλε ένα label ανά πελάτη ή περιοχή, και γράψε τα tasks κάτω
από κάθε ένα. Στο Sublime μπορείς να το αποθηκεύσεις ως `.sublime-snippet` με
tab-trigger (π.χ. `day`), ώστε μια νέα μέρα να είναι ένα πλήκτρο.

## Το εβδομαδιαίο τελετουργικό

Το format δεν αξίζει τίποτα χωρίς τη συνήθεια που το κρατάει ειλικρινές:

- **Τέλος ημέρας** — σημείωσε ό,τι έγινε `✅`. Ό,τι έμεινε ανέγγιχτο και ακόμα
  μετράει: `- ⏭️` και αντέγραψέ το κάτω από την επόμενη μέρα.
- **Τέλος εβδομάδας** (δες το θέμα `Planning` στο demo) — review της εβδομάδας,
  μετάφερε τα μισοτελειωμένα στην επόμενη εβδομάδα, κατέγραψε νέες ιδέες, βάλε
  προτεραιότητες για Δευτέρα.
- **Αρχή μήνα** — μετακίνησε το `🟩` στον νέο μήνα στο `MONTHLY PLAN`, σπάσε τους
  στόχους του στις πρώτες μέρες.

Τίποτα δεν χάνεται σιωπηλά: είναι είτε `✅`, είτε `⏭️` μπροστά, είτε `➡️` σε
κάποιον άλλον, είτε διαγράφηκε επίτηδες.

## Ρύθμιση editor

### Sublime Text

**1. Εγκατάσταση του syntax.** Στο Sublime, άνοιξε *Preferences → Browse
Packages…* — ανοίγει ο φάκελος `Packages/`. Αντίγραψε το
[`Planoptis.sublime-syntax`](Planoptis.sublime-syntax) στον υποφάκελο `User/`
(`Packages/User/`). Το Sublime το φορτώνει αμέσως, χωρίς restart.

**2. Εφαρμογή σε αρχείο.** Άνοιξε το αρχείο του plan και είτε:

- κάνε κλικ στο όνομα του syntax κάτω δεξιά στη status bar και διάλεξε
  **Planoptis**, είτε
- από το μενού *View → Syntax → Planoptis*.

**3. Αυτόματη αντιστοίχιση (προαιρετικό).** Με ανοιχτό ένα plan αρχείο και
επιλεγμένο το Planoptis, διάλεξε *View → Syntax → Open all with current
extension as… → Planoptis*. Από εκεί και πέρα κάθε αρχείο με αυτή την κατάληξη
ανοίγει ως Planoptis. Χρησιμοποίησέ το με ειδική κατάληξη τύπου `.planoptis` και
όχι `.txt`, ώστε να μη γίνουν *όλα* τα text αρχεία σου plan.

**4. Folding.** Με τα τριγωνάκια του gutter, ή από *Edit → Code Folding*
(*Fold All* / *Unfold All*, και *Fold Level 1–9*).

### Άλλοι editors

Δεν υπάρχει ακόμα έτοιμο grammar, αλλά το format έχει σχεδιαστεί να υποβαθμίζεται
ομαλά — είναι απλώς ένα indented text αρχείο:

- **VS Code** — βάλε το αρχείο σε plain text· το folding ακολουθεί το indentation.
- **Vim / Neovim** — `:setlocal foldmethod=indent`.
- **Emacs** — `outline-minor-mode` ή `origami.el`.
